# سامانه مشتریان آرایشی بانو

نسخه اولیه قابل اجرا از پنل ثبت مشتری، تأیید پیامکی، کد معرف و گزارش‌گیری.

## امکانات
- ورود امن کارکنان با نام کاربری و رمز عبور هش‌شده
- ثبت مشتری فقط از پنل کارکنان
- تأیید شماره با پیامک OTP از طریق Kavenegar Verify Lookup
- جلوگیری از ثبت شماره تکراری با قید UNIQUE در دیتابیس
- شناسه اختصاصی تصادفی ۵ رقمی برای هر مشتری
- کد معرف اختیاری و ثبت ارتباط معرف/معرف‌شده
- داشبورد، فهرست مشتریان، جست‌وجو، رتبه معرف‌ها و آمار ۷ روز اخیر
- رابط PWA قابل نصب و کش شدن فایل‌های رابط کاربری

## پیش‌نیاز
- Node.js نسخه ۲۰ یا جدیدتر
- حساب پیامکی کاوه‌نگار و فعال بودن الگوی Verify
- هاست یا سرور دارای HTTPS برای استفاده واقعی و امن

## راه‌اندازی محلی
1. این پوشه را روی کامپیوتر استخراج کنید.
2. فایل `.env.example` را به `.env` تغییر نام دهید.
3. یک رمز قوی برای پنل انتخاب و هش آن را تولید کنید:

```bash
node -e "console.log(require('bcryptjs').hashSync('YOUR_STRONG_PASSWORD', 12))"
```

4. مقدار هش را در `ADMIN_PASSWORD_HASH` قرار دهید. `ADMIN_USERNAME` را هم عوض کنید.
5. `SESSION_SECRET` را با یک مقدار تصادفی بلند (حداقل ۳۲ کاراکتر) جایگزین کنید.
6. کلید API و نام الگوی Verify کاوه‌نگار را وارد کنید.
7. نصب و اجرا:

```bash
npm install
npm start
```

8. در مرورگر باز کنید: `http://localhost:3000`

## تنظیم پیامک کاوه‌نگار
- در پنل کاوه‌نگار یک الگوی تأیید بسازید؛ مثلاً متن الگو شامل `%token` باشد.
- نام دقیق الگو را در `KAVENEGAR_VERIFY_TEMPLATE` بگذارید.
- کلید API فقط در فایل `.env` روی سرور نگهداری شود و هرگز در کد مرورگر یا اپلیکیشن قرار نگیرد.
- در صورت استفاده از متغیر دوم/سوم الگو، باید تابع `sendKavenegarOtp` متناسب با قالب پنل شما تنظیم شود.
- سرویس پیامکی ممکن است برای فعال‌سازی الگو یا ارسال خدماتی تأیید بخواهد.

## انتشار روی سرور
- روی سرور Node.js نصب کنید و پروژه را منتقل کنید.
- `.env` واقعی را روی سرور بسازید؛ آن را داخل ZIP یا مخزن عمومی قرار ندهید.
- `npm install` و سپس `npm start` را اجرا کنید.
- دامنه را با HTTPS به برنامه متصل کنید. چون کوکی نشست در حالت production امن است، HTTPS ضروری است.
- برای اجرای دائمی از یک process manager مانند PM2 یا سرویس systemd استفاده کنید.
- پوشه `data/` را در برنامه پشتیبان‌گیری روزانه قرار دهید. فایل دیتابیس `bano.sqlite` داده‌های مشتریان را نگه می‌دارد.
- در هاست چندنمونه‌ای/چندسروری، OTP حافظه‌ای را به Redis منتقل کنید و از ذخیره‌ساز نشست مشترک استفاده کنید.

## نصب روی اندروید
پس از انتشار روی دامنه HTTPS:
1. لینک سایت را با Chrome گوشی باز کنید.
2. منوی سه‌نقطه را بزنید.
3. گزینه «Install app» یا «Add to Home screen» را انتخاب کنید.

این پروژه PWA است، نه APK امضاشده. برای تولید APK مستقل می‌توان بعداً آن را با یک پوسته Android مانند Trusted Web Activity بسته‌بندی کرد.

## نکات مهم امنیت و منطق
- ثبت مشتری و شماره تکراری در سمت سرور کنترل می‌شود؛ بررسی صرفاً در مرورگر نیست.
- شناسه ۵ رقمی فضای محدودی دارد (۱۰۰٬۰۰۰ شناسه). برای سامانه بزرگ‌تر بهتر است شناسه ۶ تا ۸ رقمی شود.
- کد OTP سه دقیقه اعتبار دارد و حداکثر پنج بار امکان تلاش برای وارد کردن آن وجود دارد.
- OTP در حافظه سرور نگهداری می‌شود؛ برای استقرار چندسروری باید به Redis منتقل شود.
- گزارش هفتگی فعلی بر اساس ۷ روز اخیر است، نه هفته تقویمی شنبه تا جمعه.
- در این نسخه حذف/ویرایش مشتری وجود ندارد تا سابقه معرفی‌ها ناخواسته مخدوش نشود.
- پیش از استفاده عملیاتی، اتصال پیامک، سیاست حریم خصوصی، پشتیبان‌گیری و بازیابی اطلاعات را در محیط آزمایشی بررسی کنید.

## ساختار فایل‌ها
- `server.js`: API، احراز هویت، دیتابیس و اتصال پیامک
- `public/index.html`: صفحات پنل
- `public/style.css`: ظاهر واکنش‌گرا
- `public/app.js`: رفتار رابط کاربری
- `public/sw.js`: کش فایل‌های PWA
- `.env.example`: نمونه تنظیمات محرمانه
